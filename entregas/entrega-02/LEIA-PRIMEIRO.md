Comece pelo guia **docs/entrega02/GUIA-PRATICO.md** e pelo pedido 10248. Para executar os scripts, use o projeto local existente em `/home/giovanne/projeto-integrador-ipog`, com Docker Compose e o schema `nw` já carregado. Este pacote é um anexo documental; não contém toda a infraestrutura e a Entrega 1 para reconstruir o projeto do zero.

Escopo acrescentado: documentos aninhados, transformação relacional → documental, carga, índices e conferências de apoio. Não há implementação das análises extensas das semanas 5–7.
